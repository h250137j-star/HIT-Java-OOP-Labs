## Repository Description

This repository contains my Java Object-Oriented Programming laboratory exercises, completed as part of my Software Engineering studies at Harare Institute of Technology.

The exercises cover fundamental and advanced Java programming concepts, including classes and objects, constructors, encapsulation, inheritance, polymorphism, abstraction, exception handling, collections, file handling and design patterns.

## Laboratory Exercises

- Lab 1: Classes and Objects
- Lab 2: Constructors, `this` and Static Members
- Lab 3: Encapsulation and Access Modifiers
- Lab 4: Inheritance
- Lab 5: Polymorphism
- Lab 6: Abstraction, Abstract Classes and Interfaces
- Lab 7: Exception Handling
- Lab 8: Generics and Collections
- Lab 9: Nested Types, Enums and Records
- Lab 10: File I/O, Lambdas and Streams
- Lab 11: Design Patterns and Mini-Project
